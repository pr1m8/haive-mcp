mcp.downloader.installers.GitInstaller
======================================

.. py:class:: mcp.downloader.installers.GitInstaller

   Bases: :py:obj:`MCPInstaller`


   Installer for Git repository-based MCP servers.

   Handles cloning Git repositories and running post-install commands.

   .. rubric:: Examples

   Git installation:

   .. code-block:: python
       installer = GitInstaller()
       result = await installer.install(
           server_config,
           template,
           install_dir
       )

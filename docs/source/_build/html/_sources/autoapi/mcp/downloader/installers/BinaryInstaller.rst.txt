mcp.downloader.installers.BinaryInstaller
=========================================

.. py:class:: mcp.downloader.installers.BinaryInstaller

   Bases: :py:obj:`MCPInstaller`


   Installer for binary executable MCP servers.

   Downloads and installs pre-compiled binary executables.

   .. rubric:: Examples

   Binary installation:

   .. code-block:: python
       installer = BinaryInstaller()
       result = await installer.install(
           server_config,
           template,
           install_dir
       )

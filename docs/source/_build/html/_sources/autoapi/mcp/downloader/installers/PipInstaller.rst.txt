mcp.downloader.installers.PipInstaller
======================================

.. py:class:: mcp.downloader.installers.PipInstaller

   Bases: :py:obj:`MCPInstaller`


   Installer for Python pip-based MCP servers.

   Handles installation of MCP servers distributed as Python packages.

   .. rubric:: Examples

   Pip installation:

   .. code-block:: python
       installer = PipInstaller()
       result = await installer.install(
           server_config,
           template,
           install_dir
       )

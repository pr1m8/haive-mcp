mcp.downloader.installers.DockerInstaller
=========================================

.. py:class:: mcp.downloader.installers.DockerInstaller

   Bases: :py:obj:`MCPInstaller`


   Installer for Docker-based MCP servers.

   Handles pulling Docker images for containerized MCP servers.

   .. rubric:: Examples

   Docker installation:

   .. code-block:: python
       installer = DockerInstaller()
       result = await installer.install(
           server_config,
           template,
           install_dir
       )

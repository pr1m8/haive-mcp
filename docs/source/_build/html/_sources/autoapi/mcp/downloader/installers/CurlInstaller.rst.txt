mcp.downloader.installers.CurlInstaller
=======================================

.. py:class:: mcp.downloader.installers.CurlInstaller

   Bases: :py:obj:`MCPInstaller`


   Installer for direct HTTP downloads.

   Downloads files directly via HTTP/HTTPS without package managers.

   .. rubric:: Examples

   Curl installation:

   .. code-block:: python
       installer = CurlInstaller()
       result = await installer.install(
           server_config,
           template,
           install_dir
       )

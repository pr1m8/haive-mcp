mcp.downloader.installers.NPMInstaller
======================================

.. py:class:: mcp.downloader.installers.NPMInstaller

   Bases: :py:obj:`MCPInstaller`


   Installer for NPM-based MCP servers.

   Handles installation of MCP servers distributed as NPM packages.
   Supports both global and local installations.

   .. rubric:: Examples

   NPM installation:

   .. code-block:: python
       installer = NPMInstaller()
       result = await installer.install(
           server_config,
           template,
           Path("/home/user/.mcp/servers")
       )

mcp.client.transport.SseTransport
=================================

.. py:class:: mcp.client.transport.SseTransport(sse_url: str, post_url: str, headers: Optional[Dict[str, str]] = None, timeout: float = 30.0)

   Bases: :py:obj:`MCPTransport`


   Server-Sent Events transport for MCP communication.

   This transport uses SSE for receiving messages and HTTP POST for sending.
   Useful for streaming scenarios where the server needs to push messages
   to the client.

   Initialize SSE transport.

   :param sse_url: URL for SSE stream (receiving messages)
   :param post_url: URL for POST requests (sending messages)
   :param headers: HTTP headers for both requests
   :param timeout: Request timeout

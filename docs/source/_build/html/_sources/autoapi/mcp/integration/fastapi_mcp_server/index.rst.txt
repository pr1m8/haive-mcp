mcp.integration.fastapi_mcp_server
==================================

.. py:module:: mcp.integration.fastapi_mcp_server

.. autoapi-nested-parse::

   FastAPI MCP Discovery and Installation Server.

   This server provides:
   1. Web interface for discovering MCP servers
   2. HITL approval via web UI
   3. Server installation and testing
   4. Real-time status updates via WebSocket

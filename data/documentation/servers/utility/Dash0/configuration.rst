Transport Configuration
-----------------------

This server supports the following transport types:

* ``stdio``

For Claude Desktop configuration:

.. code-block:: json

   {
     "mcpServers": {
       "Dash0": {
         "command": "npx",
         "args": ["Dash0"]
       }
     }
   }
